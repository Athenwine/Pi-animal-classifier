🦁 Classification d'Animaux par IA

Intelligence Artificielle & Deep Learning

Système de classification hiérarchique utilisant TensorFlow et MobileNetV2
30 espèces • 6 catégories • 90%+ de précision

📚 À Propos du Projet

Ce projet de classification d'animaux par intelligence artificielle a été développé dans le cadre de nos études à ESPRIT School of Business.

Notre système utilise des techniques avancées de deep learning pour identifier automatiquement 30 espèces d'animaux réparties en 6 grandes catégories. Le modèle est basé sur l'architecture MobileNetV2 avec transfer learning, offrant une précision supérieure à 90%.

🛠️ Technologies utilisées:

  • TensorFlow & Keras - Framework de deep learning
  • MobileNetV2 - Architecture de réseau de neurones avec transfer learning
  • Flask - Framework web Python pour le backend
  • HTML5, CSS3, JavaScript - Interface utilisateur interactive
  • Python - Langage de programmation principal

🎯 Objectif: Créer un système intelligent capable d'identifier avec précision différentes espèces animales, facilitant ainsi l'apprentissage et la reconnaissance automatique pour des applications éducatives, scientifiques et de conservation.
